# Executive Storytelling

Reusable skill for improving dashboard pages through information hierarchy, executive readability, visual prioritization, and decision-oriented storytelling.

## When to use

Use this skill when:

- redesigning an existing dashboard page
- restructuring a page
- deciding what belongs above the fold
- improving executive readability
- reducing clutter
- deciding which metrics/charts deserve emphasis
- improving section hierarchy
- turning analytical data into a clearer business story

## Core principle

Do not make every page look the same.

Instead:

**Same product language + different page identity.**

Each page should have its own structure based on the business question it answers.

## Priorities

1. Business question
2. Information hierarchy
3. Executive readability
4. Visual storytelling
5. Progressive disclosure
6. Appropriate visualization
7. Interaction
8. Visual polish
9. Data integrity

## Key rule

Do not add more components simply because more data is available.

Prefer:

**Higher insight density + lower visual clutter**

## Use with other skills

This skill works especially well alongside:

- `dashboard-visual-quality`
- `chart-design`
- `kpi-card-design`
- reusable drill-down/modal patterns

It determines **what deserves emphasis and why**.

The other skills determine **how the individual components should look and behave**.

## Expected outcome

The finished page should feel:

- executive-ready
- intentional
- easy to scan
- visually balanced
- insight-driven
- premium
- consistent with the overall dashboard
- unique to its business purpose
