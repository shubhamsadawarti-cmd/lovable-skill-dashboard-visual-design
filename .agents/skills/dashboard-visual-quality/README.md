# Dashboard Visual Quality

## Purpose

This skill is used to improve the visual quality and UX of existing dashboard pages.

It establishes the dashboard's visual quality bar while allowing each page to maintain its own identity and purpose.

## When to Use

Use this skill when:

- improving an existing dashboard page visually
- refining layout and spacing
- improving typography
- improving cards and KPI presentation
- improving chart presentation
- improving colors
- improving tooltips
- improving hover states
- adding smooth transitions or subtle animations
- improving filters
- improving tables
- improving modals and drill-downs
- reducing visual clutter
- improving executive readability
- performing a visual QA pass

## What This Skill Does

The skill provides 24 visual and UX principles covering:

1. Visual hierarchy
2. Page composition
3. Section structure
4. Spacing
5. Typography
6. Color system
7. KPI/card design
8. Chart selection
9. Chart composition
10. Chart styling
11. Tooltips
12. Hover behavior
13. Animation
14. Transitions
15. Interactive states
16. Highlights and emphasis
17. Filters
18. Tables
19. Modals and drill-downs
20. Loading/empty/error states
21. Responsive fitment
22. Information density
23. Executive storytelling
24. Final visual QA

## Important

This is NOT a page template.

Do not make every dashboard page look identical.

The existing ServiceNow Campaigns page can be used as a visual quality benchmark, but each page should retain its own:

- identity
- purpose
- content hierarchy
- layout requirements
- interaction model

## Relationship With Other Skills

This skill is a page-level visual quality framework.

It can be combined with more specialized skills such as:

- `chart-design`
- `drill-down-table`
- `executive-storytelling`
- `filter-design`
- `modal-design`

When multiple skills apply, preserve the existing page's business logic and use the most specific skill for the relevant component.

## Core Principle

> Improve the dashboard without making it feel redesigned for the sake of redesigning it.

The target is a premium, polished, executive-ready experience with low cognitive load and strong usability.
