# KPI Card Design

Reusable design skill for creating and improving KPI cards, metric cards, summary metrics, and executive metric blocks.

## When to use

Use this skill when:
- creating new KPI cards
- redesigning existing KPI cards
- improving KPI hierarchy
- adding target/attainment indicators
- adding KPI drill-down behavior
- improving KPI visual quality
- fixing KPI spacing, typography, color, or interaction

## Core principle

Do not make every KPI section look identical.

The KPI design should adapt to the page's:
- identity
- purpose
- audience
- business context
- surrounding visual language

## Key priorities

1. Data correctness
2. Clear metric hierarchy
3. Executive readability
4. Intelligent number formatting
5. Semantic color
6. Clean spacing and alignment
7. Subtle interaction
8. Consistency with the existing dashboard
9. Minimal clutter
10. Premium visual quality

## Important rule

This skill controls KPI presentation and interaction.

It should not automatically redesign unrelated charts, tables, navigation, or page sections.

## Expected outcome

KPI cards should feel:
- premium
- intentional
- easy to scan
- analytically useful
- visually consistent
- appropriate for an executive dashboard
